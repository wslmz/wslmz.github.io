生物信息学简介

生物信息学研究的4个步骤

  1. question
    省流：生物信息学很重要
  2. information
  • NGS使基因测序的成本大大降低了（被誉为改变世界的三大工程之一）
  • 相比之前，数据量大大增加
  1. analysis
    以数据为背景，各种数据处理工具（生物信息学工具蓬勃发展）
  2. modeling
  • model即模型，包括linear regression,logistic regression,neural network model 等，本质是拟合数据并可能对数据进行预测的工具
  • 神经网络模型
    利用类神经元式的结构，简单的可分为3层，input layer，hidden layer和output layer,每一层包括若干类神经元，神经元之间通过大量的简单函数连接
    在机器学习中，会利用loss function不断优化参数，达到local optimum
  • 自然语言与生物信息有一定相似点，早期将语言模型用作生信模型
  • 对比：算法（algorithm）与模型
    算法，如排序算法，dynamic programming algorithm等，本质是对数据进行处理所遵循的一种逻辑
